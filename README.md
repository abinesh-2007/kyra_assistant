🤖 Kyra AI Assistant
Kyra is a voice-controlled desktop assistant built using Python.
It runs in the background, listens for a wake word, and performs tasks like opening applications, searching the web, and controlling system operations.

🚀 Features

🎤 Wake word activation ("Kyra")
💻 Open installed applications (Chrome, VS Code, Arduino, etc.)
🌐 Smart Google search fallback
📂 Create files and folders
🔍 Search files in system
🔐 Secure system controls:

Shutdown
Restart
Lock
Sleep
(with confirmation)


🗣 Voice responses for all actions
💤 Auto sleep after inactivity
⚡ Auto-start on system boot

🛠 Installation & Setup

Download assistant.exe
Run the application
Enter your Porcupine Access Key (first time only)
Restart your system
Say "Kyra" to activate the assistant


🔑 How to Get Access Key

Visit Picovoice Console
Create a free account
Generate your access key
Paste it when prompted in the app

🧠 How It Works

Runs silently in the background
Continuously listens for the wake word
Activates only when "Kyra" is detected
Uses speech recognition to process commands
Executes actions or searches intelligently


⚠️ Requirements
